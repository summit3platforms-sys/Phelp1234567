The Quick Answer

If your Bixolon printer has power and a cable connected but doesn't show up in Devices and Printers or your POS app, follow this step-by-step detection guide.

There's a specific breed of printer problem where everything looks fine on the surface — printer's powered on, cable's connected, no error lights — but the computer just doesn't see it. It doesn't appear in Devices and Printers, doesn't show up in Bluetooth settings, doesn't get detected by your POS software. As far as the operating system is concerned, you don't have a printer at all.

This one has a small handful of causes, and once you know what they are, the fix path is short.

Case 1: Windows Doesn't Detect the Hardware at All

The most common variant of this problem: you plug the printer in, or connect via Bluetooth or network, and nothing happens on the computer end. No "new device connected" notification, no entry appears in Device Manager, no printer icon in Printers & scanners.

For USB Connections

Open Device Manager (right-click Start → Device Manager) and watch as you plug and unplug the printer:

  • Nothing changes when you plug/unplug — Windows isn't seeing the physical connection. The issue is the cable, the USB port, or the printer's USB hardware. See the USB not detected guide for the full isolation process.
  • An entry appears (possibly under "Other devices" with a warning icon) — Windows sees the printer, but doesn't have a driver for it. Skip to Case 2.
  • An entry appears and disappears rapidly — physical connection problem: bad cable, damaged port, or intermittent contact.

For Bluetooth Connections

Open Settings → Bluetooth & devices and try to add the printer:

  • Printer doesn't appear during scan — likely the printer isn't in pairing mode, or (on some models like the SPP-R310) it's set to the wrong iOS/Android mode for your device
  • Printer appears but pairing fails — see the Bluetooth pairing guide
  • Printer pairs but doesn't appear in Devices and Printers afterward — this is a driver issue rather than a pairing issue; skip to Case 2

For Network Connections

Print the printer's network configuration page and verify:

  • The printer has a valid IP address
  • Your computer can ping that IP address
  • No firewall or subnet mismatch is preventing communication

If ping works but the printer still doesn't appear when you try to add it, the issue is on the Windows side rather than the network side.

Case 2: Detected, But Not Appearing as a Printer

This variant is more subtle: Windows sees a device, but it's showing under "Other devices" or "Unspecified" rather than under Printers. The device may have a yellow warning triangle or an "Unknown" label.

What's happening: the operating system recognizes something is connected, but doesn't have the right driver to identify it as a specific printer model.

Fix:

  1. Note where the mystery device appears in Device Manager (usually under "Other devices" or "Universal Serial Bus controllers")
  2. Right-click it and select Uninstall device
  3. Unplug the printer
  4. Install the correct Bixolon driver for your model and Windows version
  5. Plug the printer back in
  6. Windows should now recognize it as your specific Bixolon model

Case 3: Ghost Devices — Printer Appears But Isn't Really There

Occasionally you'll see a Bixolon printer listed in Devices and Printers even though it's currently unplugged or offline. This is normal — Windows keeps the printer entry across sessions so your print settings persist. But sometimes the entry gets stuck: the printer physically comes back online, and the entry is still there, but Windows still treats it as offline no matter what.

Fix:

  1. Right-click the printer entry in Devices and Printers
  2. Select Remove device (this removes the ghost entry)
  3. Reconnect the printer
  4. Windows will re-detect it, this time with a live connection

Case 4: Detected in Windows, Not in POS Software

If Windows shows the printer as installed and ready, but your POS platform (Square, Toast, Shopify, Clover) doesn't see it:

  • Your POS software maintains its own printer list, separate from Windows. Even a working Windows install may not automatically populate the POS app's list.
  • Open the POS app's printer or hardware settings and manually add the printer through the app's own interface.
  • Some POS platforms only detect printers of specific types — check that your Bixolon model is supported and configured correctly within the app.

Case 5: Mac Not Detecting a Bixolon Printer

macOS doesn't include drivers for most Bixolon printer models — this is different from Windows, which will at least install a generic driver. If your Bixolon printer isn't appearing on Mac:

  1. Download and install the Bixolon macOS driver package for your model from their support site
  2. Restart the Mac after installation
  3. Open System Settings → Printers & Scanners
  4. Click the + button to add a printer
  5. Your Bixolon printer should now appear in the discovery list
  6. Select it and confirm the correct driver is being used (should show the Bixolon model name, not "Generic PostScript" or similar)

Without the driver package installed first, macOS may briefly acknowledge a device is plugged in but never provide a way to add it as a printer.

Recovery Sequence: When Everything Fails

If you've tried each of the cases above and nothing helps, this recovery sequence resolves most stubborn "printer just won't appear" cases:

  1. Fully unplug the printer (power and USB/network cables)
  2. On the computer, remove every trace of the printer:
    • Devices and Printers entries
    • Driver packages in Apps & Features
    • Driver files in Print Server Properties (Devices and Printers → Print server properties → Drivers tab)
  3. Restart the computer
  4. Reinstall the current Bixolon driver as administrator
  5. Reconnect the printer only after installation completes

That single sequence — full removal, restart, clean reinstall — clears up most cases where a printer has become "stuck" in a bad state that partial troubleshooting can't recover.

When It's Actually the Printer

Some symptoms strongly suggest the issue is the printer itself, not the computer:

  • Self-test fails to print (the printer can't produce output on its own, independent of any computer)
  • Printer shows no power lights despite being plugged in with a confirmed-working adapter
  • Printer connects intermittently across multiple computers and multiple cables
  • USB port on the printer visibly damaged

In these cases, no amount of driver reinstallation will help. Contact Bixolon support for hardware evaluation.
